# My First React Scratching Project

This is a beginner-level React application built using **Vite**, **React Router**, and modern JavaScript components. It serves as my foundational practice project for understanding React component architecture, routing, and single-page application navigation.

## ✨ Features
* **Component-Based Architecture:** Built using clean, reusable functional components.
* **Client-Side Routing:** Implemented using `react-router-dom` to switch seamlessly between pages without reloading the browser.
* **Fast Build Tooling:** Powered by Vite for a lightning-fast local development experience.
